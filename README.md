# madracis_reefscape
code, analyses and figures for investigation of cryptic speciation and habitat differentiation in *Madracis* corals using a reefscape genomics approach

The following directories describe the main datasets, analyses and output for each of the reefscape genomics aspects:

[**/WGS**](https://github.com/jahoey/madracis_reefscape/tree/main/WGS)

[**/morphology**](https://github.com/jahoey/madracis_reefscape/tree/main/morphology)

[**/3D_models**](https://github.com/jahoey/madracis_reefscape/tree/main/3D_models)
