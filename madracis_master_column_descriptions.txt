Column name	Description
Date	This is the date of the dive. Format is Month/Day/Year
Tray	Color of the coral sampling tray and number of the tube in which a coral sample was put in. Recorded when recording data in the field and can be observed from Paralenz footage.
Site	Name of the dive site
Depth	Plot depth
ID	Sample ID that links genetic data with macrophotos and 3D annotations
Species	Visual species identity in the field (often incorrect)
Species_mpha	"Species identity based on initial genetic assessment, if available. MPHA has been divided up into 3 lineages"
Species_genetic	Genetic cluster identity based solely on genetics and having high % assignment to a cluster.
Davis_library	Yes or no specifies if the sample was given to UC Davis to be turned into a lcWGS library
Macrophoto	"Was a macrophoto taken? Yes or no, with the date it was taken. Tissue sampling and macrophotos were taken on the same day, in most cases. Macrophotos, renamed with 'IDs' can be found here: https://drive.google.com/drive/folders/1kRC8Z_WkONoE-AHt_ELo3qFe4vE8U8Tk?usp=drive_link. The corresponding raw images can also be found there with the 'Original_macrophoto_file_name'."
Original_macrophoto_file_name	"The original file name, as named by the Olympus TG5 camera"
Notes_macrophoto	Any comments or notes related to how certain we are about the macrophotos. Or any useful information
Notes	Notes from the field
CARMABI_backup	"Was a backup tissue sample left at CARMABI? Yes or no. Only deep samples backups were left, assuming the initial sample was large enough to break in half."
To_Do	Data management things to check on & notes left for posterity
Diver	Name of the diver who is wearing the Paralenz and did the tissue sampling
Dive_Num	Dive number of the day. Obtained from the directory where the video footage was saved.
Point_number	"Number of the annotation in the .txt file. If there is a '/', check 'Annotation_comments'"
Annotation_using_which_ply_file	ply file name used for annotations
Annotation_file_name	File name in which the point annotations were saved
Annotation_point_on_actual_coral	Yes if annotation point is on center of colony. No if annotation point is nearest point
Video_file_name	File name of the video that contains footage of the colony being samlpled
MM_SS_of_colony_in_video	Minutes and seconds of when colony sampling starts
Annotation_comments	Any comments about the point annotation
Pedro_ID	Sample ID given by Pedro & students. Indicates that coral was sampled by both Pedro and CAS
Media_file_name	"Photos/video files of the associated colony as taken by Pedro et al., if any"
